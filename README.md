## About

**Viblioo** is a social platform built around real-life experiences. Discover plans, meet new people, connect with friends and create memories together.

This repository contains the backend infrastructure and API powering the Viblioo ecosystem.

## Tech Stack

| Technology | Purpose |
|---|---|
| Java | Core programming language |
| Spring Boot | Backend framework |
| Spring Security | Security and authentication |
| REST API | Client-server communication |

## Architecture

The backend is designed to provide a scalable, maintainable and secure foundation for Viblioo's features and services.

- Modular and maintainable codebase
- Secure authentication and authorization
- API-driven architecture
- Scalable foundation for future features
